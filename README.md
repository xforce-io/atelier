# Atelier · 工坊

人和数字员工共同工作的地方。

Atelier 是一个独立项目，面向人和数字员工的持续团队协作。它以任务契约组织工作，将讨论、委派、执行、交接、检验和验收连接成可观察的交付过程。

milkie 提供底层 agent runtime；Atelier 在其上定义数字员工、任务和团队，并为接入不同 coding agent 保留边界。

## 当前状态

项目处于概要设计阶段，尚无可运行实现。文档描述目标方向，不代表已有产品能力或执行器认证。

## 首个验证场景

人提出一项代码修改目标，由数字员工执行、另一名数字员工独立检验，人验收交付。验证重点是任务不会因会话或单次执行结束而失去状态，交接有明确产出，检验对应当前版本，人无需逐条转发消息。
