# 井字棋任务输入

这是用于开发验收的缺陷基线，尚不满足交付要求：它漏判两条对角线。任务是在保留离线打开能力的前提下完成规则并交付，不要求安装依赖、联网或启动服务。

目标：3×3 本地双人，X 先手；三行、三列、两条对角线对 X/O 都正确判胜；满盘无胜者为平局；重复点击和结束后点击不改变局面；重新开始清空局面并恢复 X 先手。

供冻结检查配置使用的可访问接口：九个按钮保留 `data-cell="0"` 到 `"8"`（按行排列），状态保留 `data-testid="status"`，重开按钮保留 `data-action="restart"`。状态显示 `轮到 X`、`轮到 O`、`X 获胜`、`O 获胜` 或 `平局`。可自由调整视觉样式；检查资源位于候选目录外，不是可修改的任务输入。

缺陷已经在任务开始前固定。如果执行成员首次交付前修复了全部缺陷，应如实记录首轮通过；不能伪造一次失败来覆盖 Atelier 的返工验收。
