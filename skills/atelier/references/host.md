# 本机本人入口

按 describe 的范围和当前操作索引调用 CLI，具体参数使用该命令的 --help。管理身份可以维护工作区和获准团队，但不等于数字员工团队负责人；数字负责人自己的消息由独立运行服务唤起该成员处理。

空工作区先初始化，再建立连接、数字员工、团队和显式授权。保存对象不等于连接可用；按所选接入检查环境。显式 runtime start 后才允许后台处理；runtime status、task show、mailbox list 查询事实不启动工作。用户提交目标后，无需宿主不断轮询或串联各阶段。

回应待办时读取事项 kind、处理者、依据版本和可选动作。补充答复与实际落实分开，恢复选择不授权或解除未知。正式接受/拒绝须对应用户当前明确决定；保存 request ID、请求/任务版本、产出及检验引用和脱敏 decision-ref。缺少决定保持待办，过期则重新展示当前事实，不自动把旧“同意”用于新版。

导出使用指定 Artifact 到新目录或空目录，保留 partial 限制。导出不等于验收、合入或部署。遇到 unknown 先核对真实资源；不能修改数据库或假造停止结果以推进任务。
