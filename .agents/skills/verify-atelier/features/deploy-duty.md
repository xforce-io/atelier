# 部署职责

Issue #5。L1 `docs/design/5-deploy-duty/product.md` v0.1 Draft。确认来源是 Issue #5 期望。

范围：S1.A1–A6。无部署职责的接受关闭仍由既有人类验收路径覆盖。

## S1.A1

团队显式指定部署成员。执行者或检验者不能兼任。显示名「运维」不产生职责。

## S1.A3–A6

有 `task.deploy` 时，接受后任务保持活动，部署投递只给冻结部署成员。成功后 `outcome` 为 `deployed`，验收记录仍为接受。缺少授权时部署记录为阻塞且不投递。失败后任务不关闭，第二次提交被拒绝。

核心测试见 L2 测试映射。真实 CLI 与产品 Skill 路径尚未作为本文件的通过证据。
