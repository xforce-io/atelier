# S2 验证路径

状态：固定输入/配置准备已有基础实现及集成测试；真实成员交付未执行。标准为 [L1 v0.10 第 8 节](../../../../docs/design/1-first-team-delivery/product.md#8-验收与效果验证) 的 S2.A1、A3–A9；本文件只提供路径，不复制另一套验收标准。

## 真实入口

安排入箱、服务领取、数字员工实际执行、固定产出和阶段回复；API 与两种 CLI 分别覆盖。

## 驾驶与证据

宿主提交后退出；核对消息/投递/Run/产出因果、单活动 Run、实际加载和越界拒绝。

CLI 和产品 Atelier Skill 分别验证；需要真实成员的路径不可用 stub 或宿主脚本替代。版本、对象和原始脱敏证据对应 L1/L2 v0.10。当前 CLI 已有 input/profile import/list/show，可测试固定版本准备；数字员工 Run 与产品 Skill 基础入口已有，但两种隔离 CLI 与真实成员成功尚未提供，真实交付验收 BLOCKED，不填 pass。


## 当前实现证据边界

CLI `task execute` 与绑定 `task_arrange(action=execute)` 已支持持久安排：目标为冻结执行成员，负责人当前及冻结权限均校验；重复请求去重，不同请求并发只产生一份安排。缺配置/权限保存 blocked，不提前消费 Run 额度。数字负责人引用真实有效安排后仍要核对资源停止，安排不等于实际执行。已有 6 个核心测试与 1 个 CLI 流程测试；verify 安排后续已补齐，真实成员执行、rework 安排与完整产品 Skill 尚待实现，不勾选 S2 通过。


产出提交和停止后固定已有 7 个核心集成测试：执行成员提交说明不立即结束投递，可信资源所有者核对停止后由核心读取候选、固定内容并发布；撤权/取消只保存 partial 历史，丢终态可复用原提交，发布故障原子回滚。包含真实 `artifact show` CLI 查询。候选由测试写入、停止观测由测试注入，不是模型产出或容器隔离的通过证据。完整 S2 仍未验收。

成员文件工具新增 2 个集成测试：冻结输入准备候选、按当前身份读取/修改、调用重放、账本故障与文件清单一起回滚、删除、提交后拒写、旧快照发布拒绝、检验者只读、越界/链接拒绝、UTF-8 分段与撤权后缓存拒绝。真实 Docker 检查测试现改为经成员文件工具构造候选后提交、固定、交接和检查；候选及决定仍由测试构造，未替代真实模型与 Skill 验收。


## CLI 隔离的开发前置证据

`npm --prefix adapters/milkie run test:isolation` 运行真实 Docker 网络验证：普通 bridge 访问同一宿主 TCP 服务作为对照，隔离容器直连网关/其它宿主地址/公网/外部 DNS 均失败；只经精确目标代理取得 example.com 的实际 HTTPS 响应，未批准目标拒绝。核对内部网络 inhibit_ipv4、IPv6 关闭、非 root/只读根/无提权和代理实际停止，清理本测试标签资源。

此检查使用冻结检查镜像中的 Node 作为测试运行时，不运行 Grok/Pi/Codex，不证明受控工具、专用登录或原生续接。milkie 固定版本 e049f0b 已有受控回调、专用存储与续接核对；Atelier 的 CLI 容器及登录管理已接线，原生账号与真实模型交付仍待验证；S2.A6/A8 等完整 CLI 证明保持未验收，不能以网络检查替代。
