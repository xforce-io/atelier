# 本机只读界面

Issue #25。L1 `docs/design/25-readonly-workspace-ui/product.md` v0.3。L2 同目录 `technical.md` v0.1。

范围：S1.A1、S2.A1、S3.A1、S3.A2、S4.A1、S5.A1。真实入口是 `atelier --workspace <临时工作区> view` 和它给出的本机页面。不打开正在运行的既有团队工作区。不把单元测试记为这些项通过。

## S1.A1

`view` 指向一个已有工作区并打开页面。页面上的工作区就是这一个。指向无效路径时命令失败，不新建工作区，也不提供页面。

## S2.A1

页面上的工作成员与 `worker list` 是同一批，每名可见 id 和名称。点一名只标明点中的是这一名。没有增删改入口。

## S3.A1

点一名后，消息与这一名作为发送者或接收者的已有工作消息是同一批，更早的在前。每条可见消息 id、发送者、接收者和内容。没有工作成员发送者时发送者是「核心」。接收者是消息自己的接收者。未点成员时不出现消息。不能发送，也不按投递状态筛选。

## S3.A2

点中的这名至少有一条消息时，打开后更后的消息处于可见位置。更早的仍在同一列表中。没有条数上限，也没有继续加载。

## S4.A1

页面上的运行状态与同一时刻 `runtime status` 的 state 相同。打开页面不启动、不停止工作区运行服务。

## S5.A1

没有编辑、发送、管理成员、凭据或签名入口。查看前后 `atelier.sqlite3` 内容哈希不变，写入次数为 0，不读凭据。
